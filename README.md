# ひとことチェック（SNSリテラシー診断ゲーム）

SNSの下書きを「投稿する」か「削除する」か選んで、リテラシー力を試す10問のゲームです。
ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）なので、そのまま GitHub Pages で公開できます。

- 問題は全部で30問。毎回「投稿してOK」5問と「削除すべき」5問がランダムに選ばれます
- 分野別（個人情報、誹謗中傷、デマ、著作権、詐欺、日常）の結果と、まちがえた問題の解説が出ます
- スマホ対応、ダークモード対応
- 架空のSNS風デザインで、特定のサービスのロゴや名前は使っていません

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目 |
| `questions.js` | 問題データ（ここを編集すると問題を追加・変更できます） |
| `game.js` | ゲームのロジックと画面の制御 |
| `test.js` | 問題データとロジックの自動テスト |

## 遊び方（手元で動かす）

`index.html` をブラウザで開くだけで動きます。

## GitHub Pages で公開する

1. このフォルダの中身を GitHub のリポジトリのルートに置いてプッシュします
2. リポジトリの Settings → Pages を開きます
3. Source を「Deploy from a branch」にして、ブランチ（`main`）とフォルダ（`/ (root)`）を選んで保存します
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 問題を追加する

`questions.js` の `QUESTIONS` に、次の形で1つ足します。

```js
{
  id: 'r19',              // 他と重ならないID
  category: 'privacy',    // privacy / respect / fake / rights / scam / daily
  answer: 'delete',       // 'post'（投稿してOK）か 'delete'（削除すべき）
  text: '下書きの文章',
  explain: '解説（答えのあとに表示されます）'
}
```

`post` と `delete` はそれぞれ5問以上必要です。追加したら次のコマンドでテストします。

```
node test.js
```

## 注意

問題と解説は学習用の一般的な目安です。法律上の判断や、個別のトラブルへの助言ではありません。
